# LocaHub — versões oficiais

Este repositório distribui os instaladores, a versão portátil e as notas do LocaHub para Windows x64. O código do aplicativo e do servidor fica em repositório privado.

Para uma instalação nova, use **[LocaHub-Instalar.exe](https://github.com/mateusartur27/gestao-locacoes-atualizacoes/releases/latest/download/LocaHub-Instalar.exe)**, o instalador online de aproximadamente 58 KB. Ele mostra a pasta de instalação preenchida, permite digitar ou escolher uma pasta base gravável pelo usuário e cria internamente uma subpasta própria do LocaHub, consulta a versão estável mais recente, baixa o instalador completo e confere tamanho e SHA-256 antes de executá-lo. Precisa de internet. Se já existir uma instalação em outra pasta, desinstale-a mantendo os dados antes de mudar o destino.

O assistente1.2.0 também consulta o arquivo oficial do próprio assistente. Se encontrar uma versão interna maior, verifica tamanho, SHA-256 e identificação do produto e abre a versão nova uma única vez antes de continuar. Versões iguais ou inferiores não são executadas como atualização. Os arquivos1.0/1.1 anteriores não têm esse recurso e precisam ser substituídos uma vez nos canais de distribuição. O arquivo original não é sobrescrito. Falhas de consulta mantêm o assistente conhecido disponível; os downloads do app continuam exigindo validação. A compatibilidade futura depende dos requisitos do Windows e da infraestrutura. O checksum fica em LocaHub-Instalar.sha256.

A alternativa **LocaHub-Instalador.exe** contém uma versão completa e instala a versão incluída quando foi baixado. O processo cria atalhos, inclui o runtime .NET do app e oferece instalar o Microsoft Edge WebView2 Runtime quando necessário. O online e o assistente de desinstalação usam o .NET Framework 4.x incluído no Windows 10/11.

A [versão0.32.1](https://github.com/mateusartur27/gestao-locacoes-atualizacoes/releases/tag/v0.32.1) inclui o assistente1.2.0, aparência dos usuários nos novos backups completos e restauração inicial simplificada. Ao importar/substituir as contas, recupera suas cores; manter usuários mantém as cores atuais. Backups antigos sem aparência não conseguem recuperar preferências ausentes. O formato novo exige0.32.1+ para restaurar, e backups antigos continuam aceitos. O app mantém termos de uso/licença na ativação, aceite registrado no servidor, consulta nas Preferências e exclusão opcional de dados na desinstalação. O texto inicial e a política comercial ainda requerem identificação/contato e revisão antes da venda. Termos exibidos pelo app não exigem troca do instalador nas plataformas quando forem atualizados. Fabricante: Mateus Artur; produto: LocaHub.

Ao abrir a versão instalada, o aplicativo registra seu assistente na opção Desinstalar do Windows. Ele também fica em current/LocaHub-Desinstalar.exe. Os dados são mantidos por padrão. Excluí-los exige marcar a opção e confirmar: remove dados, usuários, ativação, preferências e cópias internas somente deste perfil do Windows, depois de concluir a desinstalação. Backups externos, licença no servidor e conversas na nuvem permanecem. A remoção direta por Update.exe conserva os dados.

Na edição portátil, extraia toda a pasta e abra **LocaHub.exe** na raiz. Mantenha current, Update.exe e os demais arquivos juntos. O assistente de desinstalação reconhece instalações; o portátil é removido pela própria pasta. Os dados ficam separados dela.

Desde a 0.30.0, o app avisa quando há atualização. Você pode consultar as novidades, baixar e escolher quando atualizar e reiniciar. O download não aplica a atualização sozinho. Versões anteriores precisam receber uma distribuição compatível uma vez.

Dados e usuários ficam fora dos arquivos substituídos pelo atualizador. Mantenha backups externos. É necessária uma licença comercial para usar o sistema. As versões anteriores continuam disponíveis.

O instalador online consulta versões publicadas; ele não publica versões. A publicação dos pacotes continua explícita após os testes do código privado. SHA256SUMS.txt, releases.win.json e LocaHub-Instalar.sha256 permitem conferir a integridade. Os executáveis ainda não têm assinatura Authenticode; a homologação interativa e os preparativos comerciais continuam pendentes.
