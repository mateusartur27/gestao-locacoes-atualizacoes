# LocaHub — versões oficiais

Este repositório distribui os instaladores, a versão portátil e as notas do LocaHub para Windows x64. O código do aplicativo e do servidor fica em repositório privado.

Para uma instalação nova, use **[LocaHub-Instalar.exe](https://github.com/mateusartur27/gestao-locacoes-atualizacoes/releases/latest/download/LocaHub-Instalar.exe)**, o instalador online de aproximadamente 63 KB. Ele mostra a pasta de instalação preenchida, permite digitar ou escolher uma pasta base gravável pelo usuário e cria internamente uma subpasta própria do LocaHub, consulta a versão estável mais recente, baixa o instalador completo e confere tamanho e SHA-256 antes de executá-lo. Precisa de internet. Se já existir uma instalação em outra pasta, desinstale-a mantendo os dados antes de mudar o destino.

Desde o assistente 1.2.0, o instalador também consulta o arquivo oficial do próprio assistente. Se encontrar uma versão interna maior, verifica tamanho, SHA-256 e identificação do produto e abre a versão nova uma única vez antes de continuar. Versões iguais ou inferiores não são executadas como atualização. Os arquivos1.0/1.1 anteriores não têm esse recurso e precisam ser substituídos uma vez nos canais de distribuição. O arquivo original não é sobrescrito. Falhas de consulta mantêm o assistente conhecido disponível; os downloads do app continuam exigindo validação. A compatibilidade futura depende dos requisitos do Windows e da infraestrutura. O checksum fica em LocaHub-Instalar.sha256.

A alternativa **LocaHub-Instalador.exe** contém uma versão completa e instala a versão incluída quando foi baixado. O processo cria atalhos, inclui o runtime .NET do app e oferece instalar o Microsoft Edge WebView2 Runtime quando necessário. O online e o assistente de desinstalação usam o .NET Framework 4.x incluído no Windows 10/11.

A versão 0.34.0 prepara o acesso à Ajuda antes da ativação/login, na recuperação de acesso e no instalador online 1.3.0. O manual permanece em preparação. Os registros de aceite anteriores são preservados. O assistente 1.2 pode buscar o 1.3 pelo mecanismo já existente.

A [versão 0.33.0](https://github.com/mateusartur27/gestao-locacoes-atualizacoes/releases/tag/v0.33.0) permite backups acima de 256 MB com processamento em blocos, mantendo criptografia autenticada e a conferência da gravação. A capacidade técnica é de 1 TiB por arquivo, sujeita a espaço temporário e tempo de processamento; os testes grandes usam mais de 260 MiB, sem prometer homologação física de 1 TiB. Backups antigos continuam aceitos; os novos exigem 0.33.0 ou posterior para restaurar. O mesmo formato é usado no agendamento e nas cópias locais. Operações grandes aguardam a confirmação nativa, e o agendamento não é interrompido automaticamente ao passar de duas horas; mantém prevenção de execuções simultâneas. Cores acompanham a importação/substituição de usuários; manter as contas conserva suas cores atuais. Também foi corrigido um descarte de paginação das mensagens durante mudanças de conexão/sincronização. O instalador online atual é 1.3.0, com acesso à Ajuda; as mudanças do app chegam pelo atualizador. Fabricante: Mateus Artur; produto: LocaHub.

Ao abrir a versão instalada, o aplicativo registra seu assistente na opção Desinstalar do Windows. Ele também fica em current/LocaHub-Desinstalar.exe. Os dados são mantidos por padrão. Excluí-los exige marcar a opção e confirmar: remove dados, usuários, ativação, preferências e cópias internas somente deste perfil do Windows, depois de concluir a desinstalação. Backups externos, licença no servidor e conversas na nuvem permanecem. A remoção direta por Update.exe conserva os dados.

Na edição portátil, extraia toda a pasta e abra **LocaHub.exe** na raiz. Mantenha current, Update.exe e os demais arquivos juntos. O assistente de desinstalação reconhece instalações; o portátil é removido pela própria pasta. Os dados ficam separados dela.

Desde a 0.30.0, o app avisa quando há atualização. Você pode consultar as novidades, baixar e escolher quando atualizar e reiniciar. O download não aplica a atualização sozinho. Versões anteriores precisam receber uma distribuição compatível uma vez.

Dados e usuários ficam fora dos arquivos substituídos pelo atualizador. Mantenha backups externos. É necessária uma licença comercial para usar o sistema. As versões anteriores continuam disponíveis.

O instalador online consulta versões publicadas; ele não publica versões. A publicação dos pacotes continua explícita após os testes do código privado. SHA256SUMS.txt, releases.win.json e LocaHub-Instalar.sha256 permitem conferir a integridade. Os executáveis ainda não têm assinatura Authenticode; a assinatura digital dos executáveis permanece pendente.
