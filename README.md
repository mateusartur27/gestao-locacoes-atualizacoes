# Gestão de Locações — versões oficiais

Este repositório distribui os instaladores, a versão portátil e as notas de atualização do aplicativo para Windows x64. O código-fonte do aplicativo e do serviço fica em repositório privado.

Baixe os arquivos na [página de versões](https://github.com/mateusartur27/gestao-locacoes-atualizacoes/releases). Use o instalador ou extraia toda a pasta portátil e abra **Gestão de Locações.exe** na raiz. A pasta `current` e os demais arquivos devem permanecer juntos. O runtime .NET acompanha; Microsoft Edge WebView2 Runtime é necessário.

A partir da versão 0.30.0, o aplicativo avisa quando uma versão nova é publicada. Você pode ver as mudanças, baixar e escolher quando atualizar e reiniciar. O download não aplica a atualização sozinho. Uma versão anterior à 0.30.0 precisa receber esta distribuição uma vez para habilitar esse fluxo.

Dados, usuários e licença ficam separados dos arquivos do programa e são preservados nas atualizações. Continue mantendo seus backups externos. É necessária uma licença comercial para usar o sistema.

Os arquivos SHA256SUMS.txt e releases.win.json permitem conferir a integridade dos downloads. Esta prévia ainda não tem assinatura Authenticode.
